# Captured fixtures

Real SSE streams recorded from the running stack, used as saved examples in the Postman
collection.

They are committed rather than captured at generation time because the assistant runs on
Gemini's free tier — **20 requests per day** — and a turn that searches costs two. Regenerating
the collection must not spend that quota.

Re-record by running a chat request against a live stack and saving the raw response here.
